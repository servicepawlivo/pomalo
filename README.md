# Pomalo Kroatisch

Kostenlose Kroatisch-Lern-App im Ling-Stil: 62 Lektionen von A1 bis B1, Wiederholung, Aussprache, Dialoge und Russisch-Brücken.

**App öffnen:** https://servicepawlivo.github.io/pomalo/

Der Fortschritt wird auf dem eigenen Handy gespeichert. Tipp: Seite in Safari/Chrome öffnen und „Zum Home-Bildschirm“ wählen – dann gibt es ein App-Icon und die App läuft auch offline.
